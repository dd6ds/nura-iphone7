# Nura on the iPhone 7 (d101, Apple A10 / T8010)

*[Deutsche Version: README.md](README.md)*

Build and boot kit for **Nura** (formerly postmarketOS) with **Phosh** on the **iPhone 7**.
Boot chain: **checkm8 (palera1n) → PongoOS → m1n1 → Hoolock Linux 7.0.12**.
The root filesystem lives either on its own partition in **internal storage**
(next to a shrunk iOS) or is served from the PC via **netboot (NBD over USB)**.

> **Experimental.** The boot has to be repeated via checkm8 after every cold start
> (tethered). iOS stays bootable, but is shrunk for the internal mode –
> make a backup first.

## Requirements

- Linux PC, preferably **Intel** with USB-A (checkm8 is flaky on AMD/USB-C hosts)
- `python3-venv` – `./build.sh deps` creates `.venv/` (pmbootstrap from Git, pyusb)
- [palera1n](https://palera.in), `libusb-1.0-0`
- For the kernel build: pmbootstrap's dependencies (builds run in a chroot)
- Lightning cable, about 15 GB of free disk space

## Quick start

```bash
./build.sh                 # deps, init, install, fixup, export, bootloader, payload
tools/kernel-custom.sh     # build the kernel with the patches in tools/kernel-patches/
./build.sh payload         # reassemble the m1n1 payload

./boot.sh                  # default: ROOT=internal (rootfs in internal storage)
ROOT=netboot ./boot.sh     # fallback: rootfs via NBD from the PC
ssh user@172.16.42.1
```

English versions of the scripts are available as `build.en.sh`, `boot.en.sh`,
`tools/*.en.sh`, `tools/*.en.py` (generated by `tools/make_en.py`, see below).

### Individual build steps

| Command | Purpose |
|---|---|
| `./build.sh deps` | check/install dependencies |
| `./build.sh init` | configure device/UI for pmbootstrap |
| `./build.sh install` | build the rootfs (including the netboot hook) |
| `./build.sh fixup` | adjust the image (firmware, services, udev rules, SSH key …) |
| `./build.sh export` | copy kernel, initramfs, DTBs to `out/` |
| `./build.sh bootloader` | fetch and patch m1n1/PongoOS |
| `./build.sh payload` | assemble `out/m1n1-linux*.bin` |

### Important variables

| Variable | Default | Meaning |
|---|---|---|
| `UI` | `phosh` | user interface (`console`, `sxmo-de-sway`, …) |
| `ROOT` (boot.sh) | `internal` | `netboot` = rootfs via NBD |
| `NURA_ROOT_UUID` | UUID of the Nura partition | ext4 UUID for internal boot |
| `NVME_BOOT` / `NVME_AUTOLOAD` | `1` | internal storage at boot / load the nvme module automatically |
| `PCIE_BOOT` | `1` | `0` = PCIe/Wi-Fi off at boot (emergency switch) |
| `PMOS_PASSWORD` | `147147` | user password – **change it for your own installs** |
| `SSH_KEY` | `~/.ssh/id_ed25519_nura_iphone` | public key is copied into the image |
| `PONGO_BOOT_CMD` | `bootm` | PongoOS command that starts m1n1 |

## Internal storage (one-time setup)

1. **Shrink the iOS container:** `tools/ios_resize.sh` (SSHRD ramdisk + `resize_apfs`).
2. **Create the partition:** `tools/nura_partition.sh check|writetest|gpt|mkfs`
   (backs up the GPT first).
3. **Copy the rootfs:** `tools/nura_copy_root.sh`, later updates with `tools/nura_sync.sh`.

The iOS partitions are exposed read-only by a udev rule.

## What is not in this repository

Apple firmware, iOS images, kernelcaches, ADT dumps and device-specific data
(serial numbers, MAC addresses, calibration data, GPT backups) are **not** published.
The scripts extract everything they need from an IPSW or from your own device.

## Troubleshooting

- **palera1n hangs at "Right before trigger":** unplug and replug the iPhone, try another USB port.
- **PongoOS not found:** `lsusb | grep 05ac:4141`, otherwise repeat the palera1n step.
- **Netboot does not arrive:** open the firewall on the USB interface (172.16.42.x).
- **SSH hangs during netboot:** start long jobs on the phone with `systemd-run` (NBD stalls).
